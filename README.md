# Weland App

A social media app for digital identity creation and community building.

## Features
- User authentication
- Profile creation and management
- Post creation and feed
- Real-time messaging
- Notifications system

## Setup
1. Clone the repository
2. Run `npm install`
3. Run `npm start`
4. Scan QR code with Expo Go app

## Build APK
```bash
eas build --platform android
